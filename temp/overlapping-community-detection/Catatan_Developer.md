## Mulai Pencatatan
### Notes 1
- Untuk data yang berasal dari API, kalo misal generate lagi itu bakal sama.
- Maksudnya adalah misal ke override, terus dibalikin nanti sama kayak data sebelumnya. Jadi dataset yang terbentuk bakal sama.
- Yang dicoba tadi, 800 ke override ke 400, terus dibalikin 400 nya gak ada perubahan. Menandakan bahwa data sebelum di overide dan generate API lagi sama aja.
- Taunya gara gara pake GIT, tadi ke override jadi Oren, setelah di generate lagi kembali seperti awal

- Aku ambil example di web dimasukin di `tsv_stringdb/` ini adalah hasil dari web.
- Kalo dari APi itu ada di `images/` itu full dari API.
